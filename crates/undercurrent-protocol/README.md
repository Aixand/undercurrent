# aixand-undercurrent-protocol

Supported Rust library for Undercurrent product requests, results, errors, and streams. Use it with the [Rust SDK](../undercurrent-sdk/README.md) to talk to a daemon.

[Encode and inspect a payload](../../docs/sdk/rust/first-payload.md), look up the [product protocol](../../docs/reference/protocol/README.md), or [find source and checks](docs/README.md).
