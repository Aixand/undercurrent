# undercurrent-python-bridge

`uc-python-bridge` connects the async Python package to an external daemon through the blocking Rust SDK. Its stdio protocol is private.

[Set up the Python client](../../python/README.md) or [build and check the matching bridge](docs/development/contributing.md#prepare-the-executable-and-python-import). See the [maintainer guide](docs/README.md) for source and verification.
