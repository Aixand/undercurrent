# Undercurrent executable failure evidence

This internal crate provides bounded private failure records for `uc`,
`uc-daemon`, and `uc-session-host`. It has no daemon connection, application
policy, configuration loader, or workload execution capability. The CLI owns
support archive collection through the public SDK.

Start with the [operator collection procedure](../../docs/guides/daemon/diagnostics.md#collect-a-support-report)
or the [maintainer notes](docs/README.md).
