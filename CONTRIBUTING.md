# Issues and pull requests

Undercurrent is publicly available, but we are not accepting pull requests at
this time. Our team currently lacks the capacity to review and support external
contributions. This includes code changes, documentation fixes, and other
cleanup. Please open an issue instead of a pull request.

Bug reports, documentation issues, feature requests, and usage questions are
welcome through [GitHub Issues](https://github.com/Aixand/undercurrent/issues/new/choose).
Search existing issues first and follow the [support guide](SUPPORT.md) when
reporting a problem. Responses and fixes depend on maintainer availability.

Report security vulnerabilities privately using the [security policy](SECURITY.md).
Follow the [code of conduct](CODE_OF_CONDUCT.md) in project spaces.
