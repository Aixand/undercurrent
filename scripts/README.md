# Undercurrent developer tooling

From the repository root, use Python 3.11 or newer to discover validation stages:

```sh
python3 scripts/validate.py --list
```

For execution prerequisites, stage selection, and evidence, follow the
[verification guide](../docs/development/verification.md). Use the
[developer tools guide](../docs/development/tooling/developer-tools.md) to
find the owning script and [tests](../tests/README.md) to find scenarios.
