# Undercurrent live product tests

From the repository root, run `python3 tests/e2e/run.py --list` to discover
available scenarios. Build matching native binaries before running a scenario.

The [live regression guide](../../docs/development/testing/end-to-end.md)
covers selection, prerequisites, and reports. For the manual Windows
peer-context probe, follow the [elevated SSH procedure](../../docs/development/testing/end-to-end.md#qualify-windows-peer-contexts).
