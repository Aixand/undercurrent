# Accomplish a task with Undercurrent

[your first session](../getting-started/README.md).
Each linked page owns its complete procedure, expected results, and recovery.

| Browse and manage sessions in a TUI | [Terminal workspace](cli/workspace.md) |
| Save and restore shell groups | [Saved groups](cli/groups.md) |
| Save and switch local instance connections | [Connection settings](cli/connections.md) |
| Connect shell hooks to a managed session | [Shell integration](cli/shell-integration.md) |

| Customize detection and input delivery | [Profiles](configuration/profiles.md) |

| Diagnose durable state or restore a backup | [Storage recovery](daemon/storage.md) |
| Investigate a failure or resource pressure | [Troubleshooting](troubleshooting.md), [diagnostics and evidence bundles](daemon/diagnostics.md) |
