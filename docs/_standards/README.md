# Apply the documentation standard

This directory contains documentation standard **0.1.0**. Keep these files
together when copying them into a project.

| Need | Guide |
| --- | --- |
| Know required content and acceptance rules | [Standard](standard.md) |
| Write and format a page | [Style guide](style-guide.md) |
| Choose and validate a visual | [Diagrams](diagrams.md) |
| Update docs as behavior changes | [Maintenance](maintenance.md) |
| Assign, perform, and review agent work | [Agent workflow](agent-workflow.md) |
| Understand the research and local precedent | [References](references.md) |

Project-specific terminology, owners, commands, and exceptions belong in the
project's own documentation. Link to them from its documentation index.
